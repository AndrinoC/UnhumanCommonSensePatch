# UnhumanCommonSensePatch
Mod to QoL left behind by the AI when the game was vibecoded. 

USAGE: Extract the three files to your game directory then run patcher.bat

The patcher modifies the game directly (package.nw\unhuman.html) and it includes the following features:
- Auto apply modifications
- Restore modifications
- Check modifications status

The current mods included in the pack are:
- Tutorial Skip Toggle + Instant Rewards
- Skip intro splash screen
- Double Click to Equip / Unequip Items
- Right-Click Context Menu Equip / Unequip

I'm open for more suggestions, you are also free to fork this and add your own mods to the bundle.
